## Grounding (repo terms, greppable - use these, not invented jargon)

Entry point: `RemoveOverlaps3D(const Manifold::Impl& in, double eps)` -> `Overlap3Result`
  (src/overlap3.h:201, src/overlap3.cpp:1293). TODAY this runs the v3 SWEEP pipeline
  (SweepEmit / BuildSlabs / EmitCaps / EmitStrips), NOT candidate B. B is a DESIGN
  validated at fragment scale, not landed C++. The doc must say so.

Mesh: `Manifold::Impl` with `vertPos_`, `halfedge_` (type `Halfedges`), `faceNormal_`.
  HALFEDGE is the repo's term (impl.h:83 `Halfedges halfedge_`; style skill line 148
  "Use existing Manifold terminology (halfedges, not DCEL)"). NEVER "DCEL".

Reusable primitives B/gate can lean on:
  - `Canonicalize(in, eps)` -> `CanonicalGeometry` (overlap3.cpp:218): input-quantized
    merged verts + `CanonicalFace{verts, normal, mult}`, mult = SIGNED multiplicity
    (overlap3.h:40-43). The signed-mult fold is where operand-of-origin is discarded.
  - `Manifold::Impl::IsSelfIntersecting()` (properties.cpp:138, impl.h:163): the
    self-collision pass. Morton/AABB broadphase (GetFaceBoxMorton) + tri-tri distance,
    shares-vertex skip, 2*epsilon relaxation. THIS is the gate's non-self-intersection
    test - NOT FindSeams. Its own comment: "not checking for epsilon-validity."
  - `IsManifold()` + `Is2Manifold()` (overlap3.cpp:1189): the validity gate.
  - collider (src/collider.h): AABB/Morton broadphase; IsSelfIntersecting and any
    arrangement enumeration broadphase both ride it.
  - `Shadows(p,q,dir)` (shared.h): the ONE global symbolic-perturbation tie-break.
  - `Winding03_` (boolean3.cpp:388): coupled winding - unite non-crossing edges, one
    ray per component, flood. The coupling discipline B inherits.
  - eps = kPrecision * bBox.Scale(), kPrecision = 1e-12 (utils.h:39, shared.h:29);
    EpsilonFromScale (boolean2.h:57). eps = machine-scale weld radius; tol = user tol.
  - Decompose() connectivity primitive exists (manifold.cpp:414 reference).

NOT reused by B (sweep-only machinery, orthogonal): BuildSlabs / SlabResolver /
  track-extension / EmitCaps / EmitStrips / cap-plane placement / FindSeams / the
  ArrangementBudget slab-memory refusal. B does NO plane sweep (S3: the O(seam^2)
  x-crossing density was a sweep-projection artifact, not radial structure).

FatalReason enum (overlap3.h:49): SubEpsInput, SubEpsFeature, NonManifoldEmission,
