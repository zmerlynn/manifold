PREREQUISITE FINDING (undercuts Stage 2 as written): the flagging machinery does NOT
localize. NonManifoldEmission is `!IsManifold() || !Is2Manifold()` on the WHOLE mesh
(overlap3.cpp:1189) with detail "emitted triangulation not 2-manifold" - no edge/vertex.
ArrangementBudget is a cumulative piece counter (overlap3_sweep.cpp:246) - no region.
SplitTouchingSheets returns a bare bool. AND emitted OutTri3D is `vec3 v[3]` with NO
provenance to input/canonical faces (overlap3.cpp:603). So Stage 2's "collect the incident
INPUT faces and GROW" has neither a SEED (which region failed) nor a MAP (emitted geom ->
input faces). Building the localizer = instrument emission provenance + make the gate
report the offending halfedge + walk it back through the sweep construction. Unnamed design
work. The doc's "the flagging machinery already exists as FatalReason returns" conflates
knowing-it-failed with knowing-WHERE.

R1 verdict: NEED-CHANGE. Cost bounded on face count (keep), but "localized clean boundary"
is refuted (model-spanning on 3 carriers), GT7081 makes C==B, and Stage 2 has no localizer.
Per-carrier honesty pass required; name the localizer as design work.

ATTACK 2 - PATCH/EXTERIOR WELD COMPOSITION  (mechanism risk)
------------------------------------------------------------------------------
There is ONE assembly weld: BuildImpl getVertIdx (overlap3.cpp:1119-1141), a uniform
hash grid cell=eps returning the min-index prior vert within Euclidean eps. EVERY emitted
triangle passes through it, exterior AND any C patch. weld_toy.py (faithful re-impl):
  2(a)  two exact-distinct patch verts 0.4 eps apart  -> MERGED. The exact arrangement
        resolved them; the assembly weld re-manufactures the twin / collapses the cell.
  2(a') the SPECIFIC Havocglass8 sliver (7.3e-4 = ~32000 eps thick) -> kept distinct.
        So THIS carrier's lump survives - but that is a property of this input's 7.3e-4
        offset, NOT of the mechanism. R3's hazard is the exact arrangement's CONSTRUCTED
        intersection verts, whose spacing shrinks with contact angle and is bounded below
        by nothing; the sub-eps critical structure (GT7081: 212961 sub-eps gaps) is direct
        evidence the hard carriers DO produce sub-eps-distinct arrangement verts.
  2(b)  a patch-INTERIOR constructed vert 0.3 eps from a shared boundary vert -> MERGED.
        Patch interior collapses onto the boundary; exact topology corrupted.
SELECTIVITY GAP: one uniform eps radius must simultaneously (i) MERGE patch-boundary onto
the exterior vert (to stitch) and (ii) NOT merge sub-eps-distinct patch-interior verts (to
preserve exact topology). A single getVertIdx radius cannot do both; the two requirements
collide exactly when the exact arrangement emits sub-eps-distinct verts, which the corpus
does. Boundary conformance answer to 2(b): the doc's "boundary verts are input verts shared
bitwise" is sound only where the clean boundary follows input edges - but the eps exterior
emits CONSTRUCTED (eps-noisy, interpolated+welded) positions even along input edges, so
patch->exterior conformance STILL relies on the eps-weld being ON at the boundary while OFF
in the interior. The doc's Stage 4 does not specify this selective/two-radius weld.

Attack 2 verdict: NEED-CHANGE. Composition is NOT sound as sketched; needs a bounded local
weld distinct from the global eps grid. Manifoldness is preserved only if the exact
arrangement never emits sub-eps-distinct verts near the boundary - which the corpus violates.

ATTACK 3 - RELOCATION SWEEP  (v3 assembly order, BuildImpl)
------------------------------------------------------------------------------
Order: getVertIdx eps-weld -> degenerate(v0==v1)/exact-dup-tri drop -> SplitTouchingSheets
-> CreateHalfedges -> IsManifold&&Is2Manifold gate -> InitializeOriginal/CalculateBBox/
SetEpsilon/SortGeometry/SetNormalsAndCoplanar. RemoveOverlaps3D is internal-seam-only (no
public post-processing).
  - getVertIdx eps-weld ............... NEEDS-BYPASS. The attack-2 relocation; uniform eps
                                        undoes exact patch-interior topology.
  - degenerate/exact-dup-tri drop ..... operates on WELDED indices; patch-safe iff the weld
                                        didn't merge -> COUPLED to the bypass above.
  - SplitTouchingSheets ............... NEEDS-CARE. Radial pairing rejects (return false ->
                                        NonManifoldEmission) on kAngleTie<1e-9 radial ties,
                                        len==0 slivers, or non-alternation. A legitimate
                                        exact patch with GENUINE tangent sheets (R6 touching
                                        contacts) is REJECTED, not composed - exact-correct
                                        patches fail-close here.
  - IsManifold/Is2Manifold gate ....... patch-safe as a gate but GLOBAL: one weld error
                                        anywhere aborts the WHOLE result (fail-closed floor
                                        preserved, but a single bad weld loses the model,
                                        not just the patch).
  - SortGeometry/SetNormals/SetEpsilon  pure reorder/recompute, no re-weld -> GENUINELY-COMPOSES.
Attack 3 verdict: NEED-CHANGE. One NEEDS-BYPASS (eps-weld) + one NEEDS-CARE (SplitTouching
tangent-reject) = Stage-4 design work the doc must name.
