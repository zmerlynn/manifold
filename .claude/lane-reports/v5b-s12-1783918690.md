### (a) LEVEL-0 RESTRUCTURING MAP (the from-input discipline at its limit)
Every combinatorial DECISION restructures to a level-0 orient predicate on INPUT:
  P1 x-shadow           -> level-0 already (1D input compare / orient1d)
  P2 y-shadow           -> orient2d(edge_xy, vertex_xy)         [LEVEL 0]
  P3 vertex-vs-face     -> orient3d(face, vertex)               [LEVEL 0]
  P4 edge-edge z-order  -> det[Q-P, S-R, R-P] and sign(den)     [LEVEL 0]
P4 PROVEN: z1 - z2 = -det[Q-P,S-R,R-P] / den, so
sign(z1-z2) = -sign(det3)*sign(den), all input coords (deciding_sweep identity check:
ok=802 over siA+GT7081, bad=0). So boolean3's level-1/2 interpolation predicates are
an EVALUATION ARTIFACT, replaceable by level-0 orient2d/orient3d. BR2's "constructed-
point precision" concern is DISSOLVED for DECISIONS: no topological decision needs a
constructed operand.

### (c) TRIPLE-POINT CONSISTENCY + the once-only rule
Does any B decision compare constructed-vs-constructed across DIFFERENT derivation
paths? Yes, potentially: PairUp orders two edge-face constructions (R1); and a triple
point (three faces) can be reached via two face-pair paths. MEASURED (triple_probe:
real triple points = 3 planes meeting inside all 3 triangles; construct 3 genuinely-
different ways - plane^3 solve, and two line(2 planes)-meets-plane paths):
  siA:      60 triple points. two-path discrepancy MEDIAN 0.585 eps, MAX 4.5M eps
            (ill-conditioned near-parallel triples); double-vs-exact error max 3.5M eps.
  openscad: median 5.9 eps, MAX 110k eps.
Comparing two INDEPENDENT constructions of the SAME triple point is UNSAFE - they
diverge up to millions of eps in the ill-conditioned tail. ONCE-ONLY (C2) RULE
REQUIRED: construct each intersection/triple point ONCE via a single canonical
derivation, store it, reference it everywhere; never compare two independent
constructions. This eliminates the constructed-vs-constructed comparison STRUCTURALLY
- mirroring the winding coupling's compute-once-flood-fill. Ordering (R1) then uses
the once-only canonical point + a level-0 (higher-degree, exact) ordering predicate.
