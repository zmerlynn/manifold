## Mission

Implement the adjudicated dead-zone-(c) fix (docs/SweepEmit3D.md "Corpus
fail-closed attribution" final paragraph + failclosed-diagnosis journal):
place each strip's c-side chain verts at the PAIR-CANONICAL critical's x, so
the cap and BOTH adjacent strip boundaries share one exact plane and closure
becomes CONSTRUCTIONAL instead of weld-dependent. Plus a
run-width/SubEpsFeature guard owning genuine macro geometry changes inside the
skipped interval.

## The bug (confirmed by reading)

EmitStrips (overlap3.cpp:683) places strips at slabs[si].xLo / slabs[si].xHi.
But the chains carry (y,z) computed at the cap plane (the pair-canonical
critical crits[li+1] where EmitCaps bound them). For a slab following a gap of
unbuilt sub-slabs, chains[ri].lo is bound at crits[li+1] (= left slab's xHi,
the cap plane) but the strip is emitted at slabs[ri].xLo = crits[ri] > that.
Same (y,z), x apart by the run width; > eps -> weld fails -> open cap-plane
holes (dead-zone c).

Key asymmetry: a slab's HI chain is ALWAYS bound at its own xHi (a slab is the
LEFT member of its pair, canonical = crits[si+1] = slabs[si].xHi). Only the LO
side of a post-gap slab is displaced (bound at crits[li+1] < slabs[si].xLo).
Same for the first built slab's lo at an opening run (bound at crits[0]).

## Plan

1. StripChains carries loX/hiX (the cap plane x per side). EmitCaps records it
   when binding (chains[li].hiX / chains[ri].loX = crits[ci]). ZipperEmit
   places each side at its chain's plane x, not the slab boundary.
2. Red-first pin: a chained skipped run wider than eps whose strips cross it,
   currently failing closed, resolving oracle-true under the rule.
   Mutation-verify.
3. Guard evaluation: does SubEpsFeature (no built-slab coverage + area >
   perim*eps) already own macro-change-in-run? Try to CONSTRUCT a slip-through
   (a face starting mid-run, extending into the right slab -> has coverage,
   guard skips, linear-interp papers over its true start). Record either way;
   tighten only if garbage results.
4. Corpus singles instrumentation: dead-zone-c hole class (displaced partners
   same (y,z), >eps in x) drops to ZERO. Record residual wall-A tails.
5. Regression: Cray pair + Offset2/3/4 keep resolving, unchanged volumes.
6. Full suite green; doc CHAIN-PLANE RULE record.

Cap: ~3 design iterations. Honest partial with the wall recorded beats a
forced green.
