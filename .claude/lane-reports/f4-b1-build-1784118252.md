Pipeline (src/overlap3.cpp @ fd2e4e07, src byte-identical to b0a473fa):

  EmitSeamedFace, then EmitCleanFaces, then BuildImpl.

- BuildImpl -> SplitTouchingSheets: open boundary = an edge with fwd.size() !=

KEY primitive fact (boolean2.h L225-231): RemoveOverlaps2D's edgeSubdiv gives
"one ordered vertex-POSITION polyline per INPUT edge ... Coincident input edges
(shared merged endpoints) get identical interior subdivisions by construction."
=> if I PRE-SPLIT each seam at the triple points (making the triple an explicit
shared input vertex), the seam-seam crossing becomes a shared vertex, NOT an
interior constructed crossing. Then pos2in ALWAYS succeeds (the triple is a
registered input vertex via pf.add, keyed by its 3D bit pattern) and all three
incident faces reference the SAME global T.pos -> weld bit-identical. The pos2in
refusal stays as a fail-closed backstop for any UN-enumerated residual crossing
(distinctly the honest wall).

## BUILD (landed)

B1 core is built in src/overlap3.cpp:
- BuildSeam.other (partner face) + two RecordSeams push sites.
- Intersect3Planes (Cramer, deterministic, guards degenerate det -> declines),
  SegProperCross2D (strict level-0 orient2d straddle), SegLineIntersect2D.
- EnumerateTriplePoints: planeId collapses coplanar faces; per seamed face,
  proper crossings of distinct-plane seam pairs name a triple keyed by the
  sorted planeId triple; ONE canonical pos per key; records (2D on-seam
  crossing, once-only 3D pos) into A.seamTriples for BOTH crossing seams.
- PlaneFrame.addAt(vec2,vec3): insert at an EXPLICIT 2D position (the on-seam
  crossing) but dedup by the 3D canonical bits.
- EmitSeamedFace pre-split: chain p0 -> triples(ordered) -> p1 via addAt, so the
  crossing is a shared registered vertex (no constructed vertex, pos2in never
  fires); byte-identical single-edge push when a seam has no triple.
- Consumption (C): winding classify + retention rule BYTE-UNCHANGED.
- Wired EnumerateTriplePoints into ResolveComponent before EmitComponentBoundary.

KEY BUILD LESSON: the FIRST pre-split used the constructed 3D triple point as the
split vertex.  That point sits ~50-190 eps OFF the seam line (Intersect3Planes
rounding + coplanar-rep planes), so the chain folded back and RemoveOverlaps2D
manufactured 3 residual crossings (2 faces) -> pos2in B3.  Fix: split at the
EXACT on-seam 2D crossing (strictly interior by SegProperCross2D) but key the
vertex by the once-only 3D pos (addAt).  After that: b3faces=0, all 574 seamed
faces build, the component reaches the emission wall.
