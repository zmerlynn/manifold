## PLAN (settled from the source read)

Pipeline (src/overlap3.cpp @ fd2e4e07, src byte-identical to b0a473fa):
- RecordSeams builds A.faceSeams[f] = {BuildSeam{p0,p1}}; pushes at L1645-46.
- EmitComponentBoundary: FoldCoplanarClusters, then per-seamed-face
  EmitSeamedFace, then EmitCleanFaces, then BuildImpl.
- EmitSeamedFace (L1801): PlaneFrame projects face+seams to 2D, RemoveOverlaps2D
  subdivides (edgeSubdiv `sub`), pos2in maps each subdivision vertex back to an
  INPUT vertex bit-exactly; a constructed crossing (no preimage) = B3 fail-
  closed (F4). Winding classify: retain iff w_above==0 (mult-1 witness).
- BuildImpl -> SplitTouchingSheets: open boundary = an edge with fwd.size() !=
  bwd.size() (L84) -> NonManifoldEmission. THIS is the hole count site.

KEY primitive fact (boolean2.h L225-231): RemoveOverlaps2D's edgeSubdiv gives
"one ordered vertex-POSITION polyline per INPUT edge ... Coincident input edges
(shared merged endpoints) get identical interior subdivisions by construction."
=> if I PRE-SPLIT each seam at the triple points (making the triple an explicit
shared input vertex), the seam-seam crossing becomes a shared vertex, NOT an
interior constructed crossing. Then pos2in ALWAYS succeeds (the triple is a
registered input vertex via pf.add, keyed by its 3D bit pattern) and all three
incident faces reference the SAME global T.pos -> weld bit-identical. The pos2in
refusal stays as a fail-closed backstop for any UN-enumerated residual crossing
(distinctly the honest wall).

B1 build (tripwire-free; no exact arithmetic on constructed points):
1. BuildSeam gains `int other` (partner face whose plane cut the seam). Two push
   sites at L1645-46. Enables naming the triple {f,g,h}.
2. planeId[f] = face2cluster[f]>=0 ? nTri+face2cluster[f] : f (collapses coplanar
   duplicates so a triple is keyed/constructed ONCE even via different coplanar
   representatives). Canonical plane per planeId from the lowest-index rep face.
3. NEW EnumerateTriplePoints(A, face2cluster): for each seamed face f, project
   its seams to f's 2D frame, test proper crossings (level-0 orient2d straddle)
   between seam pairs with distinct partner planeIds; key = sorted{planeId
   triple}; construct pos ONCE via Intersect3Planes (Cramer on the 3 canonical
   input planes; deterministic, order-independent by the sorted key); record the
   pos into A.seamTriples[f][k] for BOTH crossing seam indices.
4. EmitSeamedFace: when building `edges`, if a seam has no recorded triples push
   it as a single edge (BYTE-IDENTICAL to today); else pre-split it into a chain
   p0 -> (triples ordered by param) -> p1, each split registered via pf.add with
   canon3 = the global T.pos.
5. Consumption (C): the winding classify + retention rule are BYTE-UNCHANGED. No
   new emission case (design C theorem). The shared vertex makes the fans close.

Mutation lever (proves once-only is load-bearing): env F4B_PERFACE=1 makes
EnumerateTriplePoints back-project the 2D crossing onto EACH face's own plane
(per-face image) instead of the canonical once-only pos -> the three faces
disagree -> holes reappear (the ~121 baseline = design-a/oscad-f4 "before").

Measurement instrumentation: env F4B_DUMP=1 makes SplitTouchingSheets COUNT all
open edges (fwd!=bwd), radial ties, and material overlaps and print an
F4B_CENSUS line, then still fail closed (production semantics unchanged when the
env is unset). "before" = F4B_PERFACE=1 F4B_DUMP=1; "after" = F4B_DUMP=1 only.
