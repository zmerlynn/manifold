## ITEM (i) - THE ALTERNATION PROBE  (scratchpad/alternation_probe.py)
================================================================================

QUESTION (BR-a). PairUp (boolean_result.cpp:285-301) partitions an edge's
retained crossings into starts/ends, sorts each, pairs the i-th start with the
i-th end. Its own comment: if the order is not start-end-start-end "this
algorithm becomes a heuristic." That is a TWO-OPERAND property. On a w=2
double-covered stratum (Havoc's lump IS w=2) does the SELF case still present a
clean alternation, or does the coupled winding-delta formulation absorb it?

PAIRUP MECHANISM CONFIRMED FROM SOURCE (read, not assumed):
  - EdgePos{edgePos(1D scalar along edge), vert, collisionId, isStart}
    (boolean_result.cpp:191). AddNewEdgeVerts (:232) sets
    `direction = inclusion < 0` and pushes `abs(inclusion)` COPIES per crossing
    (:242) - multiplicity is already representable. AppendPartialEdges (:340-355)
    tags the retained endpoint verts isStart from the sign of i03 inclusion.
  - So the token's start/end tag is the LOCAL SIGN of the winding transition
    (inclusion<0), and the multiplicity is abs(inclusion). PairUp then sorts and
    pairs by 1D position (:294-301). The alternation precondition is on the
    ORDER of these local-sign tokens along the carrier.

METHOD. A w=2 stratum's token ORDER is a 1D combinatorial object: an ordered
sequence of +-1 soup-winding transitions. I exhibit it faithfully by casting
generic (non-axis) directed lines THROUGH the w=2 points (mission_lump,
right_centroid) - a transversal 1-cell chain through the lump - and reading the
EXACT soup winding w_S per cell (the same validated ray-to-exterior machinery as
coupled_winding.py, double mirror alongside). From the winding step-function I
derive per crossing: the +-1 delta, PairUp's isStart token (local sign), and
adjudicate (A) raw alternation, (B) the ballot/multiplicity generalization,
(C) the S4(c) threshold read. Grounding for "bounding polylines": S3 already
enumerated Havoc's arrangement - every seam bounding the lump is a clean
2-distinct-plane edge with ZERO interior triple-point subdivision, so the only
non-trivial token ORDER in the self-arrangement is exactly this double-cover.

RESULT (identical on all 10 lines, 5 dirs x 2 targets; double==exact throughout):

  w_cells along every line:   0 -> 1 -> 2 -> 1 -> 0
  local-sign token order:     S S E E              (expanded by |delta|)
  wmax=2  wmin=0  endpoints w=0

  (A) RAW ALTERNATION (PairUp's literal precondition): FALSE on every w=2 line.
      The sequence is SSEE, not SESE - reaching w=2 needs two consecutive
      up-steps. PairUp's stated start-end-start-end order is VIOLATED on the
      double-covered stratum. This is the doc's exact worry, now on real geometry.
  (B) BALLOT / MULTIPLICITY condition: TRUE. The winding stays >= 0 everywhere
      (wmin=0) and returns to 0. This is the multiplicity generalization of
      alternation (prefix #S >= prefix #E == w_S(t) >= 0), which boolean3's
      abs(inclusion)-copy machinery targets. Under it PairUp's sorted-pairing
      still COVERS the {w>=1} region (covers_set=True) - it does not crash or go
      non-manifold on Havoc.
  (C) THRESHOLD READ (B's S4(c) spec, doc line 425 "retain the sector whose
      w_S >= 1"): the CORRECT clean output = the boundary of the solid {w_S>=1}.
      That boundary has exactly 2 sheets per line (the outer 0|1 entry and 1|0
      exit). The interior 1|2 and 2|1 crossings are w>=1 on BOTH sides => NOT
      boundaries => DISCARDED. clean-boundary sheets = 2 on every line.

THE SHARP DIFFERENCE (grounded):
  - PairUp's local-sign pairing keeps ALL 4 crossings as output-edge endpoints
    (SSEE -> pairs (S0,E2),(S1,E3)) => 2 SPURIOUS interior sheets per w=2 line -
    the double-cover kept as overlapping doubled edges, wrong for a clean
    single-wall union / self-removal boundary.
  - The threshold read emits only the 2 clean boundary sheets and discards the
    interior double-cover natively. NO pairing, NO alternation invoked.

WHY THE TWO CASES DIVERGE (the structural reason). In the TWO-operand pipeline
PairUp's alternation holds because each operand's edges carry inclusion w.r.t.
the OTHER operand in {0,1} (clean SESE); w=2 arises only when the two retained
boundaries are composed, and the inclusion filter keeps each operand's portion
OUTSIDE the other, so the interior never reaches PairUp. In the SELF case there
is NO other operand - the natural field is the TOTAL soup winding w_S, which
REACHES 2 on the double-cover in ONE field, and PairUp's local-sign pairing then
over-emits. B does not have this problem because it never references a second
operand: it thresholds the soup winding directly.

ADJUDICATION (the task's question answered): alternation does NOT hold in the
self case on the w=2 stratum (raw SSEE), and the coupled winding-delta
formulation ABSORBS it - not by restoring alternation, but by not needing it:
S4(c) reads the integer cell winding and emits the {w_S>=1} boundary, indifferent
to token order. So B does NOT inherit PairUp: it REPLACES PairUp's 1D
position-pairing with a winding threshold. On Havoc's union corpus the winding
stays non-negative (ballot holds), so even a naive PairUp self-reuse would be
manifold-but-doubled, not a crash; the assumption's HARD break is negative
winding (subtraction; openscad's soup winding reaches -1, doc BR-d), where the
ballot condition fails and local-sign pairing mislabels - and there too the
threshold read is indifferent. B's residual "1D alternation" open is therefore
CLOSED in B's favor: it is a property of the retired mechanism, not of B.

FP: double == exact on every cell of every line (winding is the validated
integer field; no precision content).
