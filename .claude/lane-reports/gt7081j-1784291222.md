- GT7081-joined RESOLVES: STS openEdges 1310 -> 0; corridor cells emit from the

- openscad REGRESSES with the SAME blanket change: kept field gives 24 open

  themselves noise (tPos signs below ULP), so its spanning tree is genuinely
  poisoned and the nuke->probe fallback is CORRECT there.

So a blanket "keep the field" is UNSOUND.  The fix must be SELECTIVE.

FIX SHAPE (in-form, driver-level, provably no-worse): make the kept-field
emission the PRIMARY and gate it on STS + the existing re-gate; on failure fall
back to today's nuke+probe emission.
- GT7081-joined: field-emit passes STS + re-gate -> accepted (RED test -> GREEN).
- openscad: field-emit fails STS fast -> falls back to nuke+probe -> unchanged.
- Sound-no-worse: BOTH carriers' outputs still pass the SAME STS + IsSelfInter-

  the (combinatorial, reliable) field over the (grazing, unreliable) probe WHEN

  back).  Cost: a possible double emission in the conflict case (~40s for
  GT7081-joined; negligible for openscad, whose field-emit fails at STS early).
