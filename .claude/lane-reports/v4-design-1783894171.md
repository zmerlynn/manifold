## The wall (settled, do not re-derive - SweepEmit3D.md WALL-A)

ONE 3D junction V is emitted INDEPENDENTLY by two adjacent slabs' cap computations.
Root anatomy under strict-FP: V sits sub-eps in x from a cap critical; two adjacent
criticals c1,c2 (~0.01 eps apart in x) each run their OWN cap arrangement, each
emits an image of V at its own plane's extended position; a steep extension track
(~100x) amplifies the sub-eps x-gap into ~1.7 eps transverse; the two images live in
SEPARATE cap arrangements, meet only at the assembly eps-weld, and 1.7 eps > eps so
they do not merge -> twin cap sheet + micro-edge -> SplitTouchingSheets TIE/NONALT ->
NonManifoldEmission. Density variant (GT7081/hull/self_*) is the same near-concurrence
at a scale that refuses at the retained-piece budget before emission.

Five wall-A kills (settled, in-scope): weld-bump, naked/Voronoi snap, anisotropic
canonicalize, provenance-label merge, sub-eps cap-plane unification. All RELOCATE.

## Relocation test (the adjudication tool, from RSI-#3 memo)

A candidate DISSOLVES only if the near-degeneracy decision is made ONCE and
everything downstream flows from it. If the decision reappears in a different
structure (certificate ordering, incremental-update predicates, reconciliation by
position), it RELOCATES and the wall stands. Be exactly this ruthless with my own
variants.

## Key code facts established (grounding read - DONE)

- boolean2_sweep.cpp: the 2D maintained-status sweep. status_ = y-order of live
  edges at current x; block rule (ProcessEvent, 7.6.2) brackets the contiguous
  straddling block at event p, splits every bracketed edge THROUGH p, re-inserts
  sorted by gradient -> collapses dense near-concurrence to ONE shared vertex. TWO

  Winding (emits retained boundary). The order is load-bearing.

  arrangement (SweepWinding) at xMid. Independent per slab.
- overlap3.cpp emission: SlabResolver is PER SLAB. ComputeCap(c) extends LEFT slab

  resolvers, each self-locating V by extending to its own tracks. This is the

- Extension = InterpolateSafe along a per-section-vertex Track (face-edge/seam/
  in-plane/weld), resolved per eps-cluster. Weld = constant (y,z) = self-locates
  nothing.
- Provenance chains (classId) already thread per-input-edge SUBDIVISION identity
  through the 2D engine; they do NOT thread cross-CRITICAL junction identity.

### Step 2 (PROBE, variant i): certificate-order sensitivity - DONE
Built a dense near-concurrence in the PROVEN 2D engine: N=9 square chords whose
pairwise crossings pile into a sub-eps band (three exactly through center =
exact degeneracy). RemoveOverlaps2D under permuted input order and sub-eps
coordinate jitter (two sign patterns x three magnitudes 1e-6..1e-1 eps).
Signature = retained-edge count + retained macro length.

RESULT:
- INPUT ORDER: base == rev-order == rot-order, BITWISE (len 3.3444444441, edges
  13). The batch block-rule sweep is FULLY order-free - the arrangement + winding
  are independent of input edge order and edge direction-of-listing.
- PERTURBATION DIRECTION at the degeneracy: pattern 0 -> 8 edges / len 1.883;
  pattern 1 -> 10 edges / len 3.228. Each pattern is STABLE across magnitude
  (1e-6 to 1e-1 eps identical), but the two patterns differ MACROSCOPICALLY
  (len differs by 1.34, ~1.5 chord lengths). The exact-degenerate base (13/3.344)
  is a third distinct answer.
CONCLUSION: the near-degeneracy RESOLUTION is determined by the (sub-eps)
coordinate details = the certificate order, and different resolutions differ at
MACRO scale - each internally stable and order-free. This is the wall's mechanism
in miniature: independent resolutions of ONE degeneracy, fed slightly different
coordinates, diverge macroscopically. The block rule dissolves the INPUT-ORDER
coupling completely, but does NOT (cannot) make the resolution itself
coordinate-free - the resolution is a real, load-bearing decision. Hence any
architecture must make that decision ONCE and flow it downstream; made in >1
independent place (v3's per-cap arrangements fed extended coords, or a KDS's
drifted certificates) the resolutions diverge = the wall. The relocation test,
made empirical.

IMPLICATION for the variants: the batch collapse is order-free + generic-stable
because it re-derives from INPUT each arrangement. An incremental KDS (variant i)
would consume CONSTRUCTED coords across events, reintroducing exactly the
cross-place resolution divergence this probe shows is macroscopic. So variant (i)
trades away the property that makes the collapse stable.
