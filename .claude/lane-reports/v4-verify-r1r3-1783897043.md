## Method

The 2D engine IS a global batch collect: MergeVerts (canonicalize) -> incidence
pre-split -> CollectArrangement (Smith 7.6.2 block-rule collapse of dense
near-concurrences, exact-lex event set + exact predicates) -> Winding. Reusing it
as the instrument is exactly what the doc does (probe 2, and variant iii's "batch
2D engine survives as the per-critical collect kernel"). I drive it with three
fixture families:
- OPEN pencil: N chords crossing sub-eps near origin, nExact exactly concurrent
  (an exact degeneracy). Ill-posed winding field. Signature = retained length /
  signed x-moment.
- CLOSED pencil: the SAME chords, each closed into a thin triangle of macroscopic
  area. Well-posed UNION (Add). Oracle = union area (Lipschitz) + retained length.
- CLOSED rect-stack / crossing-chain: near-coincident features whose input verts
  sit sub-eps apart so MergeVerts/canonicalize is ACTIVE and transitive (span >
  eps) - to probe the merge/grouping step directly.

Perturbations: (a) input-ORDER permutations (reverse, rotate, shuffles; edges AND
vertices+remap), signature compared BITWISE (hexfloat-exact); (b) sub-eps
coordinate JITTER, two-to-four deterministic per-vertex sign patterns x magnitudes
1e-6..0.9 eps.

## R3 - conclusion: BREAK (refined)

The macroscopic divergence appears ONLY on the OPEN (non-closed) field and VANISHES
on EVERY closed field - monotone union AND sign-cancelling alike. The discriminator
is CLOSEDNESS (a well-defined winding number everywhere), not monotonicity: an
open curve has undefined winding at its dangling ends, so a sub-eps change in the
central near-concurrence can flip an ENTIRE chord's retention (a macroscopic object)
-> macro length jump. A closed curve's boundary moves only sub-eps, so area AND
length are Lipschitz (spreads 0.15 eps / 0.65 eps at unit scale).

Therefore probe 2's HEADLINE - "the resolution difference is MACROSCOPIC (> a chord
length)" - is an ARTIFACT of the open-chord ill-posed winding field. The refined,
defensible pillar: the spread-vs-distinct resolution is a REAL coordinate-determined
LOCAL-topology decision (usedVerts still shift 45->40), but on WELL-POSED CLOSED
input its metric consequence is EPS-BOUNDED (Lipschitz), not macroscopic. Structural
backing: a UNION's boundary is a Lipschitz function of vertex positions, so a sub-eps
near-concurrence cannot flip a macro region's inside/outside - only rearrange the
boundary locally by O(eps). Caveat kept honest: the 3D wall lives on CLOSED input
and manifests as a LOCAL non-manifold twin - which is exactly the eps-bounded
local-topology decision that SURVIVES the refinement. So R3 breaks the pillar's
"macroscopic" WORDING and probe 2's chosen evidence, not the design conclusion that
the local resolution must be made once and coherently.

## R1 - conclusion: SURVIVES (with a named design requirement)

Variant (iii) does NOT relocate into an order-sensitive grouping predicate. Across
477 sweep-order checks (exact-degenerate + near-concurrent + jittered) the block-rule
collapse is BITWISE input-order invariant; the one-crowd/two-crowd grouping is

WHAT makes it stable (the design requirement for the 3D lift, stated precisely):

Variant (i)'s incremental KDS violates (1) by consuming constructed coords across
events. So R1 stands: (iii) dissolves BECAUSE it re-derives-from-input and
canonicalizes ONCE; (i) relocates by giving up (1); v3's wall is the failure of (2).

## Synthesis (the doc's corrected claim)

A global batch collapse is stable - order-free AND bounded-consequence - under two
measured conditions: (1) the collapse is re-derived from input coordinates via an
exact-coordinate, order-independent event ordering (no discovery-order-dependent
consumption of constructed coordinates), and (2) each near-degenerate cluster is
canonicalized exactly ONCE. Under those conditions the spread-vs-distinct resolution
remains a REAL coordinate-determined decision but its consequence is a BOUNDED, LOCAL
topology choice on the closed (well-posed) field - eps-scale in area and length -
NOT the macroscopic divergence probe 2 reported (which was the open-chord winding
artifact; verified vanishing on both monotone-union and sign-cancelling closed
inputs). The 3D collect of variant (iii) - canonicalize verts + seams + crossings,
once, globally, feeding cluster disambiguation - satisfies BOTH conditions
STRUCTURALLY: its input is closed solids (condition 2's well-posedness is free), and
a single global collect is by construction the from-input, canonicalize-once machine
that v3's per-slab independence is not. So R1 SURVIVES (iii dissolves, does not
relocate) and R3 BREAKS the "macroscopic" framing: the resolution is not free, but on
well-posed input its cost is a bounded local defect (the non-manifold twin), not a
macro geometry error. Cross-lane note for R4: because the cost is local/eps-bounded,
the doc's "macroscopic => research-grade" inference for the disambiguation core is
