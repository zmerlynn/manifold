## Design

AxisDropFrame replaces PlaneFrame's orthonormal (origin/e1/e2) basis:
- proj(P) = SELECT the (axis+1, axis+2) coordinate pair (dominant normal axis
  dropped), swapped when nHat[axis] < 0 (parity: 2D-CCW -> +nHat). Pure
  coordinate selection, no arithmetic -> no rounding. Affine, so on-line feet /
  param sorts stay consistent.
- lift(q) = inverse for a 2D-BORN point: undo the swap, solve nHat.P = planeD for
  the dropped (dominant, |nHat[axis]| >= 1/sqrt(3), nonzero) coordinate.
- Edge-on degeneracy is IMPOSSIBLE for a valid plane (dominant-axis pick) -
  asserted (DEBUG_ASSERT), not branched.
- Back-projection: prefer direct-3D construction where a 3D source exists
  (seamed cen3 = direct 3D sub-tri centroid, prototype's approach); plane-solve
  lift only where 2D-born verts must lift (fold new crossings + fold interior
  probe).

JunctionSplitsOnSegment decoupled from the frame type (takes the two projected
endpoints q0/q1, not a frame ref) so the seamed path can migrate while fold/clean
stay on PlaneFrame for one commit. Frame-agnostic (the on-line foot is affine).
