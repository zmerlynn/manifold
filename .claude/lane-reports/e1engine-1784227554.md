fan4=1), all in ONE near-tangent multiply-wound cluster: 17 seamed faces
{228,229,232,257,259,260,262,283,285,286,314,315,316,325,391,419,420}, planes
within ~22 eps, winding 0..3, eps=3.519e-10.

ROOT CAUSE (pairdiag/fracture/floodclose/final18): per-face-INDEPENDENT emission.
Each face builds its own axis-dropped 2D arrangement, subdivides shared lines by a
face-kind-specific junction filter (onCarrier plane-membership = asymmetric at
super-concurrencies), retains cells by a per-face-local winding probe (cen +/-
eps*nHat, NOT cross-face consistent). The only cross-face coordination is the
eps-weld (BuildImpl) + radial fan-pairing (SplitTouchingSheets). At the near-tangent
cluster this is insufficient. Two facets:
- SUBDIVISION (T-junction): coincident sub-edges get mismatched endpoints.
- RETENTION: a boundary sub-edge whose coincident neighbour is a thin near-tangent
  cell whose CENTROID reads buried/exterior (w+=1/w-=2 or w+=-1/w-=0) but whose
  EDGE at the open location is a genuine manifold boundary; per-cell centroid
  BothSidesRetain drops it -> the shared edge is emitted one-sided (partner ABSENT,
  fan2=0 = never mispaired).

CORRECTED DESIGN (the E1 retention half - spec 2, done RIGHT):
