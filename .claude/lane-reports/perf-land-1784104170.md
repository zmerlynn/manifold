### SOUNDNESS AUDIT of the BVH broadphase - VERDICT: PASS
CROSSING-SUPERSET PROOF (exactness-compatible, no box inflation): if the segment
p->seed genuinely crosses triangle T (WindCrossTri delta!=0), the exact crossing
point x is a convex combination of the segment endpoints (so componentwise
min(p_k,s_k) <= x_k <= max(p_k,s_k)) AND of T's vertices (so
min(a,b,c)_k <= x_k <= max(a,b,c)_k).  The query box Box(p,seed) and T's leaf box
are exactly those componentwise min/max of the SAME doubles the predicates read
(min/max of doubles is exact; Box(p1,p2) = la::min/la::max, common.h:272), so x
witnesses the closed-interval Box::DoesOverlap (<=/>=, common.h:436) and T is a
candidate.  The Morton sort only orders leaves (never drops a box).  QED.
THE ONE DIVERGENCE (not a superset violation): the walk over-conservatively
re-seeds when p or seed lies exactly on a DISTANT triangle's plane the segment
never reaches (delta==0 there); the winding is single-valued off-surface so the
BVH's value from that seed already equals the walk's next-seed value - strictly
more permissive, never wrong.
EMPIRICAL RAILS (PL_VALIDATE: per-query BVH-vs-walk value equality + a full
crossing-superset scan): windDiverge=0 AND windSupersetViol=0 on siA, siB,
GT7081, openscad (its resolving component), gt7863.  The relaxation never fired;
every genuine crossing triangle was in every candidate set.  Output FNV ==
baseline on all carriers (below).  No soundness hole; land as-is.
