KILL (S-mult): RemoveOverlaps2D's winding pass needs FLOW-CONSERVING signed input -
every edge part of a closed oriented loop, so mult balances at each vertex (ComputeCap's

along the triangle boundary), which is CIRCULAR - you need G to set up the arrangement
that computes G.  So the steer's "arrange under a WindRule" does NOT map: the seam
polylines' winding-delta semantics are open arcs, not the closed signed loops
RemoveOverlaps2D/ComputeCap consume.  This is the recorded kill the steer asked for.

crossing-split + eps-merge via edgeSubdiv), then extract the arrangement CELLS and
