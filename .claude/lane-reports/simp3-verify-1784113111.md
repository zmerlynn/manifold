## Item 1 - cleanPierce -> WindCrossTri decision-equivalence (case analysis)

cleanPierce(owner,tgt) tests, for each of owner-triangle To's 3 edges (u,w), a
strict-interior pierce of target triangle Tt=(Tt0,Tt1,Tt2).

OLD (base): sgn(a,b,c,d) = filter; if 0 escalate to exact. Per edge:
  su = sgn(Tt0,Tt1,Tt2,u); sv = sgn(Tt0,Tt1,Tt2,w);
  if (su==0 || sv==0 || su==sv) continue;         // (A) on-plane / same side
  o1=sgn(u,w,Tt0,Tt1); o2=sgn(u,w,Tt1,Tt2); o3=sgn(u,w,Tt2,Tt0);
  if (o1==0||o2==0||o3==0) continue;              // (B) crossing on tri boundary
  if (o1==o2 && o2==o3) return true;              // (C) strict interior pierce

NEW (HEAD): WindCrossTri(Tt0,Tt1,Tt2, u, w, delta) && delta!=0, per edge.
WindCrossTri (dbCached=kWindDbLive):
  da=filter(Tt0,Tt1,Tt2,u); db=filter(Tt0,Tt1,Tt2,w); escalate each on 0.
  if (da==0||db==0) return false;                 // -> && delta!=0 is FALSE
  if (da==db) return true; (delta stays 0)        // -> && delta!=0 is FALSE
  o1=filter(u,w,Tt0,Tt1); o2=filter(u,w,Tt1,Tt2); o3=filter(u,w,Tt2,Tt0); esc.
  if (o1==0||o2==0||o3==0) return false;          // -> && delta!=0 is FALSE
  if (o1==o2 && o2==o3){ delta = dot(seed-p,n)>0?1:-1; } return true;

Mapping, arm by arm (identical filter-then-exact per orient site, identical
argument order Tt0,Tt1,Tt2 for the plane and (u,w,Tti,Ttj) for the edge chain):
- da==su, db==sv exactly (same predicate, same operands, same exact escalation
  including the true-coplanar exact-zero = 0 result).
- Arm (A): su==0/sv==0/su==sv  <->  da==0/db==0 (return false) OR da==db (return
  true but delta==0). BOTH yield "no pierce this edge". The da==db exact-zero /
  same-side arm survives because the decision gates on delta!=0, and delta is
  ONLY ever set nonzero in the o1==o2==o3 branch. MATCH.
- o1/o2/o3 identical (same operands, same filter-then-exact).
- Arm (B): any o==0 -> old continue / new return false (delta 0). MATCH.
- Straddle but not all-equal (o's nonzero, not o1==o2==o3): old falls through (no
  return true) / new returns true with delta==0 -> && delta!=0 FALSE. MATCH.
- Arm (C): o1==o2==o3 -> old return true / new sets delta=+/-1 (the ternary is
  strictly +/-1, never 0, even if dot==0 exactly -> -1) and returns true, so
  && delta!=0 is TRUE. MATCH.

delta's SIGN is discarded by the delta!=0 test; the extra cross/dot in
WindCrossTri only computes that sign. Orient-call count per edge is identical
(5: da,db,o1,o2,o3 vs su,sv,o1,o2,o3), each filter-first, no new exact-kernel
site. VERDICT: bitwise decision-equivalent INCLUDING every exact-zero arm.
Empirical corroboration: FNV memcmp below (witnesses that reach RecordSeams'
phantom-seam guard: EntangledBars/BarsCrossZ via the resolver, GT7863/GT7081/
siA/siB dirty components, openscad).
