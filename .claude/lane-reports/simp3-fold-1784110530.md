### Item 1 - cleanPierce -> WindCrossTri fold
Equivalence re-derived at HEAD: cleanPierce(owner,tgt) for edge (u,w) vs tri Tt
maps to WindCrossTri(Tt0,Tt1,Tt2, u, w, delta): da/db == su/sv (same
filter-then-exact plane-side), o1/o2/o3 == same edge-edge chain same order,
strict-interior pierce == (WindCrossTri true AND delta!=0). da!=db forces
dot(w-u,n)!=0 so delta is +/-1 exactly on the interior branch. WindCrossTri's
extra cross/dot only sets delta's SIGN (>0.0); decision tests delta!=0 only ->
bitwise-identical verdict, no new exact-kernel call (WindCrossTri is already
filter-first).

cleanPierce witness per the Claude lane, hash unchanged incl fail-closed detail).

inventory (both sites). clang-format-20 rewrapped the new comment (comment-only,
