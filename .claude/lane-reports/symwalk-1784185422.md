### DESIGN of the symbolic cell walk (the swap)
- Provenance map A.provOf : canon3-bits -> VProv (trivial v | cramer 3 planes).
  Every wedge-face arrangement vertex is covered:
    * triangle corners + input-vertex T-junctions = TrivialHPoint (W==1);
    * interior triple points + wedge splits = CramerHPoint{sorted plane-triple reps}
      (bit-identical to the Intersect3Planes canon the seamTriples store);
    * seam endpoints = CramerHPoint{plane(f), plane(g), plane(edge-neighbor)} where
      the endpoint lies on a triangle edge of f or g (edge = plane(owner) INT
      plane(pair-across-edge)); reconstructed geometrically + VERIFIED chk~=P, else
      the wedge face fails closed (no symbolic point -> never emit).
    * junction splits dedup to an actual raw member (seam endpoint / triple / input
      vert) -> already in provOf.
- ExtractCellsSymbolic: replace atan2 radial sort with an EXACT CCW angular
  comparator built from HomogOrient2D(center, a, b) on the HPoints (filter-first,
  escalate to exact; reference-ray = an arbitrary neighbor, collinear tie-break via
  a non-collinear witness - ALL orient2d on real arrangement points, no infinity, no
  new form).  signMul from the CCW triangle corners aligns HomogOrient2D's frame to
  verts2 (handles axis-drop parity/flip).  Outer face = the unique min-double-area
  loop (|outer| ~ model^2 >> sliver eps^2), dropped; all other loops kept as bounded
  cells in walked (combinatorially-CCW) order.  Winding via the existing 3D
  both-sides rule (untouched).  Lever SYMWALK_OFF -> double ExtractCells (the 56).
