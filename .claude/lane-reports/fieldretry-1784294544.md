GT7081's JOINED component (both twin shells welded at the seam into one
19352-tri connectivity component, the largest of the composed pair's 13
components) fails closed at SplitTouchingSheets: 1310 dangling boundary edges =
872 real corridor cells the engine DROPPED.  Root cause chain:
1. flood conflict (4 cycle-closing dihedral-handoff edges, delta=1 vs a

   spanning-tree field (overlap3.cpp ~5857) -> emission falls back to per-cell

   deltas are the wrong arm; the tree drops them); on openscad the tree edges

2. the near-tangent probe then reads wA==wB on genuine boundary cells, and the
   LADDER-CONSISTENT NON-BOUNDARY heuristic (~5825-5833) flips those to
   non-boundary, silently tearing the sheet instead of a clean cert-fatal.

## The fix (this lane)

1. DRIVER FIELD-RETRY (EmitCoordinatedBoundary, ~6053): consume attempt 1 with
   keepField=true (suppress the nuke); on ANY fatal fall back to the SAME code
   path keepField=false (today's nuke+probe, bit-identical).  keepField threaded
   as a defaulted bool param into EmitCoordinatedBoundaryImpl; the nuke gated
   `flMismatch>0 && !keepField`.  Retry only does real work when a conflict
   fired.
2. SUB-WELD GATE on the heuristic (~5831): add `fn.extW <= 0.99*eps` so it only
   welds sub-weld-thin cells; a MACRO grazing cell reaches the honest cert-fatal
   (moot once the field path is primary, but closes the silent-tear mechanism).
