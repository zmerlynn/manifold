BUG FOUND: M3 exposes a double-cap issue. When two criticals c1 < c2 are within
eps (the slab [c1,c2] is `built=false`), both look up the same (leftIdx,
rightIdx) adjacent slab pair in EmitCaps -> DOUBLE CAP -> NonManifoldEmission.

FIX: In EmitCaps, track emitted (leftIdx, rightIdx) pairs in a std::set and
skip any critical whose slab pair was already emitted. This is the correct
M3 companion fix: M3 removes the over-eager pre-dedup, EmitCaps deduplicates
by effect rather than by proximity.
