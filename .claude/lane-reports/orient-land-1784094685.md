plane), it returns 0 (no seam) ONLY if BOTH exact orient3d == 0 (edge exactly IN
the plane). When the guard does NOT fire (at least one endpoint exactly
OFF-plane), the code FALLS THROUGH to Orient3DSoS (su, sv), which is TOTAL and
decides the straddle/pierce exactly.

Filter-only would be `if (fu==0 && fv==0) return 0;` -- fires for ALL filter-0
pairs, INCLUDING near-tangent transversal straddles where the two endpoints are
each within filter-eps of the plane but on OPPOSITE sides (exact orient3d != 0,
opposite signs). Such an edge genuinely pierces; the exact guard routes it to
SoS. Filter-only would return 0 (no pierce) unconditionally, WITHOUT routing to
SoS -- a definite geometric "no seam" answer, i.e. a SILENT GUESS, not a
fail-closed refusal.
