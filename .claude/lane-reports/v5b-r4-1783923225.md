## DESIGN: the level-0 restructuring of the enumeration decisions
================================================================================

Round-3's exact enumeration (fragment_havoc.py / multisheet.py) decides a genuine
face-pair crossing by: solve3 for a point p0 on the plane-plane line L, then
tri_line_interval clips L to each triangle via sign(dot(n, cross(dir, v - p0)))
on the CONSTRUCTED p0 (a LEVEL-2 constructed-point predicate - exactly ATTACK 3a's
finding), then overlaps the two param intervals (lo>=hi). None of that is level-0.

The restructured form decides the SAME genuine crossing with orient3d on INPUT
coordinates only (S2's map), decomposed into the task's four decision classes:

  D1 FACE-PAIR OVERLAP (plane straddle). For pair (i,j):
       sj[k] = orient3d(ai0,ai1,ai2, bj_k)   k=0,1,2   (tri j vs plane i)
       si[k] = orient3d(bj0,bj1,bj2, ai_k)   k=0,1,2   (tri i vs plane j)
     All input face + input vertex => LEVEL 0. If all three sj same nonzero sign
     (tri j entirely on one side of plane i) => no crossing. Likewise si. This is
     the necessary straddle gate; short-circuits.

  D2 EDGE-PLANE CROSSING EXISTENCE. Read off D1 signs: edge (a_u,a_v) of tri i
     crosses plane j iff si[u], si[v] have opposite sign. The isolated vertex
     (unique sign) fixes the two boundary edges of each triangle's L-interval.
     No new orient3d - a structural read of D1's signs.

  D3 SEGMENT-vs-TRIANGLE / EDGE-EDGE Z-ORDER (the centerpiece = P4 class). The
     transversal genuine crossing is decided WITHOUT constructing L, as: "some
     edge of one triangle pierces the interior of the other." Edge (u,v) of tri i
     pierces tri j = (aj0,aj1,aj2) iff (i) u,v straddle plane j [D1: si_u, si_v
     opposite] AND (ii) the pierce point is INSIDE tri j:
       orient3d(u,v, aj0,aj1), orient3d(u,v, aj1,aj2), orient3d(u,v, aj2,aj0)
       all the SAME sign.
     The three (ii) predicates are edge-vs-edge determinants det[u-v, ...] on FOUR
     input vertices = exactly the P4 z-order determinant class (they resolve the
     radial/z ordering of the pierce point against tri j's edges). Genuine crossing
     <=> (some tri-i edge pierces tri j) OR (some tri-j edge pierces tri i). This
     is the SAME orient3d shape the fragment already uses+trusts for the winding
     ray crossing (winding_filtered o1/o2/o3), so consistency with the winding half
     is structural; and it is provably equivalent to the exact enum's positive-
     length interval overlap for transversal pairs (an overlap endpoint is always
     an interior pierce of one triangle by an edge of the other). It sidesteps the
     Guigue-Devillers canonical permutation, lowering implementation risk while
     remaining a level-0-orient3d theorem. LEVEL 0.

Every D1/D3 orient3d runs through the Shewchuk static filter (o3derrboundA =
(7+56u)u, u=2^-53; ratio=|det|/errbound; ratio>1 CERTIFIES the double sign) with
an exact-Fraction fallback, counted PER CLASS. Constructed intersection POSITIONS
(the once-only segment cache) may remain double - they are output geometry, not
decisions.

GRADE: the restructured filtered enumeration's genuine-crossing SET must equal the
round-3 exact enumeration's set PAIR-FOR-PAIR (the exact enum is the oracle). Any
pair where the filtered pierce-decision and the exact interval-overlap disagree is
a FINDING (root-caused: transversal mismatch = bug; tangential/coplanar boundary =
measure-zero contact both should exclude). Cell/winding classification must still
match recorded exact ground truth. Same asserts armed as round 3 (cocycle, >2
