## Grounding notes (code read complete)

- FindSeams (overlap3.cpp): pairwise face loop; shared-edge (>=2 shared verts) exemption FIRST;
  then coplanar test (all 3 verts of B within eps of A's plane, then A of B); then EdgeInPlane;
  then TriTriSeam; degenerate/collapsed seams push endpoint x's into arr.criticalXs. M1 pass:
  seam pairs SHARING A FACE feed SeamSeamCrossX -> criticalXs (strictly-interior crossings only,
  near-parallel gate eps*(lenA+lenB)).
- BuildSlabs (overlap3_sweep.cpp): crits = all vert x's + criticalXs, sorted unique (IEEE-exact
  unique only). Slab built iff width > eps. Sections at xMid; FaceTrack carries the two 3D edge
  pairs; seamTracks = seams whose 3D x-span contains xMid, keyed by yzMid eps-match.
- Extension (overlap3.cpp ExtendPtWithSeams): endpoint interior to face segment (> eps from both
  ends) -> seam-track eps-match on yzMid -> else WELD-constant; endpoint near segment end ->
  class-i face track. Per-PIECE-endpoint today; the design's mechanism 3 moves this to
  per-section-VERTEX with class-iii = in-plane member boundary edges.
- Chain binding: EmitCaps binds chains only at the PAIR-CANONICAL critical (ci == li+1);
  non-canonical caps in a sub-eps run emit geometry but bind no chains. ChainSplitVerts scans the
  cap arrangement's FULL vert set per strip edge.
- Coplanar detector: one DIRECTION at a time (B-in-A's-plane tested first; if the eps test
  passes, `continue` fires WHETHER OR NOT interior overlap holds - the A-in-B test is skipped for
  that pair). Membership predicate for the design's union-find is "the existing detector's test"
  = 3-verts-within-eps-of-plane, either orientation.
- Design mechanism 4 adds: in-plane boundary-edge crossing x's of grouped faces to criticalXs.
  Critical set for a coplanar group per design = {vertex x's} + {seam-seam crossing x's} +
  {in-plane boundary-edge crossing x's}.

Attack order: R4 criticals completeness -> R5 eps boundary -> R6/R7 test surface + resolver.
