================================================================================
MISSION 1: FORMALIZE the decision system at a generic self-triple point
================================================================================

SETUP. A self-triple point p = f /\ g /\ h : three sheets (faces) of ONE oriented
soup S meet. Three pairwise seams s_fg = f/\g, s_gh, s_hf, each a LINE through p.
In each face the two incident seams cross at p: face f sees s_fg x s_fh, etc.

DECISION VARIABLES (the tuple a protocol must output):
  D1 CROSSING EXISTENCE per seam-pair per owning face: does the finite SEGMENT of
     s_fg cross the finite SEGMENT of s_fh inside triangle f?  (segment extent is
     bounded by triangle f AND the partner triangle, e.g. s_fh's extent needs p in
     triangle h.)  3 booleans at p (one per face), plus the far crossings.
  D2 1D ORDER along each of the 3 seams: the sequence of triple points / endpoints
     along s_fg, s_gh, s_hf.  A total order per seam.
  D3 RADIAL ORDER at the node: cyclic order of the incident sheets around each seam
     edge (the fan pairing).
  D4 IDENTITY / ALIASING: which constructed points coincide (p itself may be a
     >3-plane concurrency; two near triple points may alias).

CONSISTENCY CONSTRAINTS for the emitted complex to CLOSE (BuildImpl/weld/manifold):
  C-seam:  each seam s_fg is shared by faces f,g.  The sub-edge subdivision of s_fg
           produced in f's arrangement must EQUAL the one in g's (same split points,
           same order) -> so the halfedges weld.  Needs D1,D2 to AGREE across f,g.
  C-radial each seam edge borders exactly 2 emitted sub-faces per sheet pair; the
           radial pairing (D3) must be a consistent cyclic matching.
  C-vert:  D4 must be an equivalence relation (transitive) or the weld tears/folds.
  C-wind:  cell winding is a coupled integer (cocycle), FP-safe; boundary emitted
           where {w_S>=1} flips.  (Decoupled from D1-D4; not a wall - sd-self sec 3.)

REALIZABLE vs ADMITTED.  A tuple is REALIZABLE iff some actual point set in R^3
produces exactly those D1-D4.  The constraints C-* ADMIT a larger set (any tuple
that welds combinatorially).  The obstruction lives where a protocol emits a tuple
in ADMITTED \ REALIZABLE: it welds locally but no geometry realizes it, so a
global inconsistency (open fan / non-manifold) appears.

KEY SUB-RESULTS (each proven/measured below):
  R-order  (probe a): along ONE seam, the per-face projected order is INTRINSIC in
     exact arithmetic (MONOTONICITY, proof below).  Cross-face disagreement is
     ROUNDING-ONLY and vanishes if the order is computed ONCE (shared).  A shared
     1D order is a total order => ALWAYS realizable.  So D2 has NO joint-non-
     realizability under a compute-once protocol.
  R-radial (attack22-c3): D3 level-0 free from input normals, 0 ties -> realizable.
  R-ident  (nomerge): D4 level-0 free (aliasGap=0), decidable by input incidence.
  R-exist  (D1): existence needs SEGMENT EXTENT (partner-triangle bounds) + orient2d
     on constructed near-tangent points.  UNCERTAIN in double (filter-0 ~22.7% in
     the wedge regime, homog-design).  BUT a CACHED (compute-once) double sign, even
     WRONG, yields a REALIZABLE arrangement (floor3/floor4 below): a wrong-but-cached
     sign realizes a perturbed-but-genuine geometry (Smith's own invariant).

PROOF (R-order monotonicity).  Seam s in plane f, direction d=n_f x n_g.  Face f
drops its dominant-normal axis (never d's, since d _|_ n_f).  Two points P,Q on s,
P = p0 + u*d.  f's projected 1D parameter t_f = (kept-2D of d) . (kept-2D of P)
= const + u*(sum of squares of d's kept components) = const + u*|d_kept|^2, and
|d_kept|^2 > 0 (d not along the dropped axis).  So t_f is STRICTLY MONOTONE in u,
for EVERY incident face.  Hence all faces agree on the order along s in exact
arithmetic.  QED.  Disagreement is only double-rounding of |d_kept|^2*(u_P-u_Q)
when u_P-u_Q ~ machine-eps (the near-tangent tail: f4-junction's t=0.9999 vs
1.0001).  Compute-once removes it.

PROBE (a) - shared-position 1D compares along DIFFERENT carriers of one point pair.
  RESULT: NOT a fundamental obstruction.  Along ONE seam s the per-face projected
  order is INTRINSIC (monotonicity proof, mission 1: t_f = const + u*|d_kept|^2,
  slope > 0 for every incident face).  Two carriers can order two points OPPOSITELY
  ONLY via double-ROUNDING when |u_P - u_Q| ~ machine-eps (the near-tangent tail;
  f4-junction's t=0.9999 vs 1.0001).  A ONCE-ONLY single seam parameter (compute t
  once, both faces consume it) removes it.  A shared 1D order is a total order =>
  always realizable.  So position-sharing + single-parameterization DEFEATS (a).

PROBE (b) - block-rule grouping in the owning face vs the 1D positions consumers see.
  RESULT: REAL for PER-FACE Boolean2 (class B counterexample above), because the
  block rule groups by eps-proximity ON THE PER-FACE SWEEP LINE - a per-face METRIC.
  Two triple points P,Q on shared s_fg: their SEPARATION as projected differs by
  face (drop different axes).  NOTE the projected LENGTH along an in-plane seam is
  near-full in every incident face (each drops its own normal axis, which the seam
  avoids), so the disagreement is bounded and near-tangent-scale - but at the
  near-tangent scale it flips the group/no-group decision.  merge-in-f / distinct-
  in-g => sub-edge-count mismatch => open fan.  CURE: a GLOBAL grouping (decide
  merge ONCE, e.g. index-SoS / a single sweep), which is exactly what class C uses
  and class B lacks.  So (b) kills the CURRENT pipeline, not the global-order ideal.

PROBE (c) - cluster snap changing crossing EXISTENCE for a seam whose OTHER face is
  NOT in the cluster's triple.
  RESULT: the SHARPEST kill of protocol-3 (cluster snap).  Two variants:
   3a SNAP THE NEAR-PARALLEL WALLS parallel: a seam s_fg in the cluster is the
      intersection of walls f,g whose PLANES move under the snap.  Moving g's plane
      moves ALL of g's seams, including where g crosses a FAR wall m at {g,m,*} that
      is NOT near-tangent and NOT in the cluster.  By E4 the far motion is
      2e5..2e8 * eps -> it can DESTROY or CREATE the far {g,m,*} crossing (change
      EXISTENCE), and face m (outside the cluster) never learns of the snap ->
      cross-face inconsistency at m.  KILLED (diameter amplification + probe c).
   3b SNAP THE CONSTRUCTED POINTS (keep planes fixed, quantize triple points to a
      shared micro-arrangement): does NOT resolve thinness (walls still near-

      A cluster-local decision leaks to a non-cluster consumer of the shared seam.
