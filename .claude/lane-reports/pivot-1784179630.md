neighborhood to one representative."  A population is CLEANLY collapsible iff its
pairwise-distance spectrum has a GAP: a radius r* below which structure is tight
and above which nothing merges until the mesh scale.  With a gap, ONE envelope
anywhere in the gap collapses everything identically and locally.  Gap-free =>
no natural collapse radius => the collapse either amplifies (large envelope) or
leaves an arbitrary percolating boundary (small envelope).  Measured by
single-linkage clustering (union-find, edge iff dist<=r) at a radius sweep;
diameters in eps units.

================================================================================
SKETCH (the 2D-block-rule lift, docs/Boolean2.md).  Smith's 2D rule groups
near-tie sweep events into a BLOCK and decides per-block consistently.  3D
analogue for the self case:
  - events   = the constructed triple points on the ONE global sweep order
    (a single maintained total order threaded bit-identically into every face;
    order is level-0 free - attack22 radial, nomerge identity, monotone seam
    arclength).
  - blocks   = maximal sets of events within the certified rounding envelope
    along the sweep direction.
  - rule     = every incident face consumes the block-collapsed position/order
    (one representative per block, keyed by index-SoS), so all faces on a shared
    seam split it identically -> the halfedges weld.
CONSISTENCY REQUIREMENT: the single global grouping must satisfy every face's
local incidence.  It FAILS iff an ODD-TRIPLE exists: face f needs a,b merged and
face g needs a,c merged with b,c distinct (the cross-face grouping that killed
per-face Boolean2).
