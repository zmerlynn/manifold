terms are the Edelsbrunner-Mucke SoS cascade, computed by Shewchuk expansion
arithmetic over an e-polynomial (map exponent-key -> coeff expansion). Perturb
entry (row r, coord c) by e^(2^(rank(r)*3+(2-c))); rank = order of the 4 global
indices. Sign = sign of lowest-exponent nonzero coefficient.
CONSISTENCY PROOF (local rank reduction is exact for the single global
perturbation): monomial exponents are sums of DISTINCT powers of two, so integer
order = compare bit-position SETS from the top; the map local-rank r -> global
rank G(r) with (r*3+(2-c)) -> (G(r)*3+(2-c)) is strictly MONOTONIC (case r<r':
delta <= -3+2 < 0; case r=r': c'-c), so the leading monomial is invariant. Hence
the per-predicate local-rank sign == the sign under one global perturbation ->
any two predicates about the same config decide consistently.
